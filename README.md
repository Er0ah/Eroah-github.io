# Eroah-github.io

Portfolio personal de Eroah para publicar notas y writeups de ciberseguridad.

## Publicar un writeup

Guarda cada nota como un archivo Markdown (`.md`) dentro de `_writeups/`. Conserva el contenido de Obsidian debajo de este bloque inicial:

```yaml
---
title: "Nombre del writeup"
category: "Laboratorio"
description: "Resumen breve opcional"
---
```

El título es obligatorio para identificar cada página; la categoría y la descripción son opcionales. Cada archivo se publicará como una página y aparecerá automáticamente en la sección Writeups de la portada.

Se admite Markdown estándar. Los wikilinks (`[[otra nota]]`), callouts y embeds propios de Obsidian no se convierten automáticamente; usa enlaces e imágenes Markdown para que se vean en la web.
